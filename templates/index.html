COLLEGE CAPSTONE PROJECT

SKYCAST — Intelligent Weather Monitoring & AWS Multi-Instance Cloud Platform

An enterprise-grade, high-availability meteorological analytics platform engineered to demonstrate cloud resilience, load distribution, and real-time API aggregation.

Project Objectives

  • Deploy a resilient dual-EC2 compute tier behind an AWS Application Load Balancer.
  • Implement automated instance metadata retrieval via secure IMDSv2 protocol.
  • Integrate real-time, zero-key meteorological telemetry through the Open-Meteo REST API.
  • Provide dynamic rule-based insights and interactive Chart.js visualization.
  • Deliver zero-config, one-click Windows startup for college lab evaluation.

Technology Stack

Python 3.11+ Flask Microframework Vanilla CSS3 (Glassmorphism) HTML5 & ES6+ JavaScript Chart.js Visualizations Lucide Vector Icons AWS EC2 (Ubuntu 22.04) Application Load Balancer Auto Scaling Group AWS CloudWatch Amazon DynamoDB Nginx Reverse Proxy Gunicorn WSGI

High-Availability Architecture

Incoming traffic hits the Internet-Facing Application Load Balancer across multiple Availability Zones. The ALB continuously polls /api/health on port 80. If an EC2 instance fails or experiences high load, traffic is automatically isolated to healthy nodes while Auto Scaling spins up replacement capacity.
